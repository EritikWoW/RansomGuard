# Icon provenance

The four Activity SVG files were supplied directly by the user for this project.
Their bytes are preserved in src/RansomGuard.Ui/Assets/Activity and SHA-256 values
are stored in manifest.json. Conversion to native WPF DrawingImage is a rendering
representation, not a new design or an assertion of ownership.

The earlier 40 bundled path-only glyphs and layered brand shield remain for other
UI controls. No font files, network assets or third-party SVG runtime were added.
Public redistribution rights should be reviewed by the publisher; this package
makes no new license assertion for user-supplied/previously included artwork.
